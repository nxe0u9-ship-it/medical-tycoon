# 🏮 와글와글 포장마차

## 1. 프로젝트 소개

**와글와글 포장마차**는 제한 시간 안에 손님들의 주문에 맞춰 타코야끼와 오코노미야끼를 만들어 서빙하는 타임어택 요리 게임입니다.

Python과 Streamlit을 활용하여 제작하였으며, 마우스 드래그 앤 드롭 방식으로 재료를 조합하고 음식을 조리할 수 있습니다.

플레이어는 사장님 이름과 포장마차 이름을 직접 정하고, 자신만의 포장마차를 운영할 수 있습니다. 레벨이 높아질수록 손님을 응대할 수 있는 시간이 짧아져 더욱 빠른 판단과 정확한 조작이 필요합니다.

**게임 바로가기:** https://tgj2w36ywfwpsmbfbxfsrj.streamlit.app/

## 2. 사용법

### ① 게임 시작

1. 배포된 Streamlit 웹사이트에 접속합니다.
2. 사장님 이름과 포장마차 이름을 입력합니다.
3. '게임 시작하기' 버튼을 클릭합니다.
4. 게임 선택 화면에서 원하는 메뉴를 선택합니다.

### ② 타코야끼 가게

1. 반죽과 문어를 조합한 재료를 조리판에 드래그합니다.
2. 치즈 주문인 경우 조리 중에 치즈를 추가합니다.
3. 6초 동안 조리한 뒤 완성된 타코야끼를 접시로 옮깁니다.
4. 가쓰오부시를 올립니다.
5. 손님의 주문에 따라 오리지널 소스 또는 명란마요 소스를 추가합니다.
6. 완성된 타코야끼를 해당 손님에게 드래그하여 서빙합니다.

조리가 완료된 타코야끼를 15초 안에 접시로 옮기지 않으면 음식이 탑니다.

### ③ 오코노미야끼 가게

1. 반죽을 조리판에 드래그합니다.
2. 돼지고기, 해산물, 치즈 중 주문에 맞는 재료를 추가합니다.
3. 앞면이 익으면 뒤집개를 드래그하여 뒤집습니다.
4. 뒷면까지 익힌 뒤 접시로 옮깁니다.
5. 손님의 주문에 따라 소스, 마요네즈 또는 소스와 마요네즈를 모두 추가합니다.
6. 완성된 음식을 해당 손님에게 드래그하여 서빙합니다.

앞면 조리 완료 후 뒤집기까지, 뒷면 조리 완료 후 접시로 옮기기까지 각각 8초의 제한 시간이 있습니다.

오코노미야끼 가게는 타코야끼 5레벨을 클리어하면 잠금이 해제됩니다.

### ④ 배경 꾸미기

배경 꾸미기 페이지에서는 포장마차의 분위기를 변경할 수 있습니다.

- **배경:** 벚꽃 축제, 여름 축제, 가을 야시장, 겨울 포장마차
- **손님 스타일:** 축제 손님, 학생, 직장인, 캐주얼
- **말풍선 스타일:** 둥근 말풍선, 강조 말풍선, 심플 말풍선

선택한 설정은 게임 화면에 반영됩니다.

## 3. 주요 기능 설명

### ① 사용자 입력 기능

`st.text_input()`을 활용하여 사장님 이름과 포장마차 이름을 입력받습니다. 입력한 정보를 `st.session_state`에 저장하여 게임 선택 화면에 '사장님 이름의 포장마차 이름' 형식으로 표시합니다.

### ② 드래그 앤 드롭 조리 기능

재료, 조리 도구, 완성된 음식을 마우스로 드래그하여 조작할 수 있습니다. 재료를 놓는 위치와 조리 순서에 따라 게임이 진행됩니다.

### ③ 5단계 레벨 시스템

각 게임은 총 5레벨로 구성되어 있으며, 레벨이 올라갈수록 손님 대기 시간이 짧아집니다.

| 레벨 | 레벨 제한 시간 | 동시 등장 손님 |
|---|---|---|
| 1 | 50초 | 3명 |
| 2 | 55초 | 3명 |
| 3 | 60초 | 3명 |
| 4 | 65초 | 4명 |
| 5 | 70초 | 4명 |

5레벨의 제한 시간을 합하면 **총 300초(5분)**이며, 시작 및 레벨 전환 카운트다운은 별도입니다.

### ④ 손님 주문 및 대기 시간 관리

손님마다 주문 내용과 대기 시간이 무작위로 결정됩니다. 대기 시간이 지나기 전에 올바른 음식을 서빙해야 하며, 손님의 표정과 대기 게이지를 통해 남은 시간을 확인할 수 있습니다.

### ⑤ 목숨과 점수 시스템

게임은 목숨 3개로 시작하며, 주문을 잘못 서빙하거나 손님이 기다리다 떠나면 목숨이 감소합니다.

주문을 성공적으로 처리하면 점수를 획득하고, 연속 성공 시 콤보 보너스가 적용됩니다. 목숨이 모두 소진되면 게임이 종료되며, 다음 레벨에 진입하면 목숨이 3개로 회복됩니다.

### ⑥ 음식 조리 상태 및 이미지 변화

음식의 조리 상태에 따라 진행 게이지와 안내 문구가 변화합니다. 접시에 담긴 음식은 가쓰오부시와 소스 등의 추가 여부에 따라 이미지가 바뀌므로 조리 진행 상황을 시각적으로 확인할 수 있습니다.

### ⑦ 게임 잠금 해제 기능

타코야끼 5레벨을 클리어하면 오코노미야끼 가게를 이용할 수 있습니다. 개발 및 기능 확인을 위한 테스트용 잠금 해제 기능도 마련되어 있습니다.

## 5. 프로젝트 특징

이 프로젝트는 단순히 버튼을 클릭하는 게임에서 벗어나, 플레이어가 직접 재료를 옮기고 조리 과정을 수행하도록 구현한 것이 특징입니다.

또한 손님의 주문, 조리 시간, 대기 시간, 레벨별 난이도를 함께 고려해야 하므로 시간 관리와 순서 판단이 중요합니다. 사용자 이름 입력과 배경 꾸미기 기능을 통해 플레이어가 게임에 직접 참여하고 자신만의 포장마차를 운영하는 경험을 제공하도록 제작하였습니다.
